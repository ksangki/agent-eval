# 에이전트 성적표 — 잘 하는가와 값을 하는가를 한 장으로 판정하는 법

> **초판 초안 (v1.0.0) — 저자가 원고 전문을 검토하기 전에 공개한 판본입니다.** 표지는 임시 타이포그래피 표지이고, 외부 검토를 받은 뒤 다음 판에서 반영할 예정입니다. 내용은 바뀔 수 있습니다.

에이전트를 들여와 파일럿을 돌리고 나면 "이 에이전트가 값을 하느냐"는 질문이 온다. 이 책의 출발점은 GDPval 표 2다. 같은 모델, 같은 과제에서 사람이 검토하고 고치는 시간을 계산에 넣자 속도 배율이 90~327배에서 0.46~1.39배로 내려왔다. 품질 실패는 검토·재작업 시간이 되어 가치 항목으로 들어온다. 그래서 이 책은 **품질·가치·감독 항목을 한 장에 적는 성적표**를 설계하고, 행마다 측정 상태(잼·일부·재지 못함)와 결과를 보기 전에 적은 합격선·중단 기준을 붙인다.

장마다 그 장의 결정에 쓸 **가져갈 도구**(성적표 양식·계산서·대조표·원장·점검표)를 두어 모두 18개를 남겼고, 근거가 약한 전망은 **가설 카드** 8장으로 떼어 부록 B의 2027년 말 점검표에 모았다. 한 고객센터의 가상 상담 요약 에이전트를 책 전체에서 따라가며 각 도구를 같은 사례에 적용한다. 사례 속 숫자는 모두 설명을 위한 예시 값이다.

## 차례

**1부. 지금의 숫자를 다시 읽는다**
1. 품질과 가치를 한 장에
2. 그 숫자는 어떻게 쟀나
3. 공개 벤치마크를 읽는 법

**2부. 값을 하는가**
4. "해결"은 누가 세나
5. 절감 시간에서 빼야 할 것
6. 정답 한 건의 원가
7. 성과는 어디서 재나

**3부. 판정의 규칙**
8. 승인률이 높을 때
9. 합격선을 먼저 적는다

**4부. 평가를 만드는 쪽**
10. 평가셋은 현업과 만든다
11. 채점기를 보정한다
12. 회귀를 잡는 정기 평가

**맺는 장**
13. 누가, 언제 판정하나

## 이 책은 어떻게 만들어졌나

이 책의 리서치와 초안은 공개 저장소의 책 저술 하네스(book-writer v2.1.0) 위에서 AI 에이전트들이 썼다 — 웹·논문·커뮤니티 리서치와 합성, 계획과 계획 검토(저자 승인), 저술 전 사실 대조, 저자 인터뷰 아홉 문항, 장별 저술과 사실 검증, 그림, 편집 통합, 교정, 앞 단계와 맥락을 공유하지 않는 수락 검수. 저자는 주제·독자·형식을 고르고, 계획을 승인하고, 가상 사례를 고르고, 인터뷰에 답했다. 경험을 묻는 질문에 "없어"라고 답한 곳은 공개 자료만으로 썼다. 이 판본의 작업 기록에는 저자가 원고 전문을 검토한 기록이 없다. 본문 그림 14점은 각 장 원고의 사실과 예시 값만으로 스크립트가 그린 도식이고, 표지는 글꼴과 도형만으로 그린 임시 표지다. 자세한 내용은 책의 서문과 부록 C에 있다.
